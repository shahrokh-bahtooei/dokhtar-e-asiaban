# دخترِ آسیابان؛ قصه‌ای با فعل‌های سادهٔ فارسی

قصه‌ای که همهٔ ۲۷۷ فعلِ فهرستِ «افعالِ سادهٔ متداول» پرویز ناتل خانلری در آن آمده و هیچ فعلِ مرکب یا پیشوندی ندارد. جدولِ همراهش برای هر فعل مصدر، امر، صورتی که در قصه آمده و فعلِ مرکبی را که جایش می‌نشیند می‌نماید، تا فعل‌های ساده را در گفتار و نوشتار بورزیم.

**[قصه را در صفحهٔ وب بخوانید](https://shahrokh-bahtooei.github.io/dokhtar-e-asiaban/)**
