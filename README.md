# دخترِ آسیابان؛ قصه‌ای با فعل‌های سادهٔ فارسی

قصه‌ای که همهٔ ۲۷۷ فعلِ فهرستِ «افعالِ سادهٔ متداول» پرویز ناتل خانلری را به کار می‌برد و هیچ فعلِ مرکب یا پیشوندی ندارد. جدولِ همراهش برای هر فعل مصدر، امر، صورتِ به‌کاررفته در قصه و فعلِ مرکبی را که جایش می‌نشیند نشان می‌دهد؛ برای تمرینِ به‌کاربردنِ فعل‌های ساده در گفتار و نوشتار.

**[قصه را در صفحهٔ وب بخوانید](https://shahrokh-bahtooei.github.io/dokhtar-e-asiaban/)**
