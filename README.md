# دخترِ آسیابان؛ قصه‌ای با فعل‌های سادهٔ فارسی

قصه‌ای با هر ۲۷۷ فعلِ فهرستِ «افعالِ سادهٔ متداول» از پرویز ناتل خانلری، بی هیچ فعلِ مرکب یا پیشوندی. جدولِ همراهش برای هر فعل چهار چیز را می‌نماید: مصدر، امر، صورتی که در قصه آمده و فعلِ مرکبی که جایش می‌نشیند. قصه و جدول را برای این ساخته‌ایم که فعل‌های ساده را در گفتار و نوشتار بورزیم.

**[قصه را در صفحهٔ وب بخوانید](https://shahrokh-bahtooei.github.io/dokhtar-e-asiaban/)**
